# Estructura inicial

Descargue Starter_SDD_IA.zip, incorpórelo a su repositorio y siga su README. Proporciona carpetas, plantilla de PR y exportador de fuente Markdown a JSON, sin resolver reglas del negocio. Lea las instrucciones del check de CI: debe detectar divergencia sin regenerar primero. La equivalencia con otro stack o herramienta está permitida.
